# analissi-siniestros-viales
Diseño e implementación de un data warehouse para analizar siniestros viales en CABA (datos abiertos, 2019–2025). Desarrollé el proceso ETL en Python y el modelo dimensional en esquema estrella; el equipo explotó los datos con Google Looker Studio. Trabajo en equipo de 4 para la materia de Business Intelligence.
